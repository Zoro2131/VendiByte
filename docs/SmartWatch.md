# VendiStep Smartwatch Design

## Purpose

The smartwatch companion extends VendiStep beyond the phone.

The watch can display:

- Current step progress
- Game information
- Collected items
- Animated collectibles

Exact capabilities will depend on the connected watch and
supported health features.

## Collectible Watch Features

Items can provide different watch features depending on rarity.

### Common

Common items can:

- Be displayed as a static image
- Be used as a watch background

### Uncommon

Uncommon items can include:

- A small animation
- A sound effect

### Rare

Rare items can include:

- A GIF-style animation loop
- Sound
- Additional animation when activated

### Legendary

Legendary items can include:

- An animated loop
- Sound
- A special action when tapped
- More elaborate interaction than lower rarities

## Example: Plastic Zombie

A collectible zombie could appear on the watch.

The zombie normally:

- Staggers around the watch face
- Remains visible as a small animated character

When tapped:

1. The zombie raises its arms.
2. It walks toward the player/viewer.
3. A small step counter appears.
4. It walks for approximately 3–5 steps.
5. It returns to its normal animation loop.

This provides an example of how higher-rarity collectibles can
become interactive watch content.
