# VendiStep MVP

## Goal

Build a complete playable version of the core VendiStep concept
while keeping the architecture scalable for future vending
machines and features.

## Required

- Complete walking-to-token gameplay loop
- User authentication
- Step tracking
- Daily login reward
- 5,000-step token rewards
- Step Freeze system
- Roll Token balance
- Vending-machine rolling
- Rarity system
- Item inventory
- Duplicate handling
- Collection screen
- Persistent backend storage
- Two functional vending machines
- Architecture capable of supporting additional machines

## Vending Machines

The MVP should contain two complete vending machines.

Each machine should have:

- Its own theme
- Its own item collection
- Complete roll functionality
- Collection tracking
- Item reveal functionality

## Smartwatch MVP

Initial smartwatch functionality should focus on:

- Displaying step information
- Receiving relevant game information
- Testing collectible display

Advanced interactive collectibles can be added after the core
system is proven.

## Not Required for MVP

- Trading
- Friends
- Leaderboards
- Large numbers of vending machines
- Seasonal events
- Complex achievements
- Social systems
- Extensive interactive watch collectibles
